# ترحيل الروابط القديمة

الموقع السابق كان على WordPress. المنظومة الحالية **مكتملة**، وهذه الوثيقة تشرح
أجزاءها حتى لا يُبنى نظامٌ موازٍ لها.

## الأجزاء

| الجزء | الملف | الدور |
| --- | --- | --- |
| التحويلات التنفيذية | `firebase.json` (`hosting.redirects`) | ٣٠١ من العنوان القديم إلى الجديد |
| تحويلات الخادم | `server.mjs` | ما لا تغطيه الاستضافة |
| حارس التقاعد | `scripts/verify-legacy-retirement.mjs` | يمنع سقوط التحويلات الحرجة |
| ترحيل النطاق | `scripts/verify-domain-migration.mjs` | canonical والنطاق المركزي |
| الروابط الساكنة | `scripts/check-static-links.mjs` | روابط الناتج المبنيّ |
| **التدقيق الجامع** | `scripts/audit-legacy-links.mjs` | الجرد والسلاسل والحلقات والوجهات |

## التدقيق الجامع

```bash
npm run legacy:audit      # تقرير كامل في reports/
npm run legacy:ci         # حارس تراجع للحرج وحده
```

يجمع الجرد من: `firebase.json` · `server.mjs` · الأزواج الحرجة في حارس التقاعد ·
ملفَّ تصدير Search Console إن وُضع في `reports/search-console-urls.csv` · الروابط
الداخلية القديمة داخل `src/` و`scripts/` و`docs/` · وsitemap المبنيّ إن وُجد.

ويكشف لكل رابط: الوجهة، وعدد القفزات، والصفحة النهائية، وهل الوجهة معروفةٌ في
جدول مسارات التطبيق، وهل بقي الرابط القديم في sitemap.

**صدقٌ في التصنيف:** أكواد الاستجابة الحيّة (200/404/5xx) لا تُدَّعى بلا شبكة؛ ما
لا يُثبت يُوسم `unverified` بدل أن يُخترع له كود.

## القواعد

- ٣٠١ عند وجود بديلٍ دائمٍ مباشر · ٤١٠ للمحذوف نهائياً بلا بديل بعد التأكّد.
- لا يُحوَّل كل مفقودٍ إلى الرئيسية — الحارس يرصد ذلك.
- لا ٣٠٢ لتحويلٍ دائم · لا حلقات · لا سلاسل (قفزةٌ واحدة).
- `trailingSlash: false` موحَّد، وحالة الأحرف في المسارات الإنجليزية محفوظة،
  والأحرف العربية المشفَّرة تُختبر كما هي.

## حارس CI

`npm run legacy:ci` يُخفق على الحرج وحده: الحلقات، والسلاسل، والتحويل المؤقّت
لوجهةٍ دائمة، وسقوط رابطٍ حرج، وأصلٍ محليّ مفقود، ورابطٍ داخليّ ما زال قديماً.
**ولا يُخفق لرابطٍ خارجيّ عارض** — الخارجيّ ليس تحت يدنا، وإسقاط البناء عليه
يُعلّم الفريق تجاهل الحارس.
