# مجموعات Firestore

الموقع يعمل كاملاً بلا Firestore — المحتوى الثابت في `src/data*` هو الأساس،
وFirestore طبقةُ إثراءٍ وتحرير. تعذُّرها لا يوقف التصفّح.

| المجموعة | المحتوى | القراءة | الكتابة |
| --- | --- | --- | --- |
| `articles` وملحقاتها | المقالات المنشورة ومتونها | عامة | أدمن |
| `books` · `papers` · `media` · `events` | إثراء المكتبة | عامة | أدمن |
| `views` | عدّاد المشاهدات | عامة | الخادم |
| `journeys` | انتقالات الزائر المجمَّعة | أدمن | الخادم |
| `analytics_events` | أحداثٌ عامة مجهولة | أدمن | الخادم |
| `admin_tool_events` | قياس أدوات اللوحة (خاصّ) | أدمن | أدمن |
| `podcast_dialogues` | الحوار اليدوي المقفول ببصمته | أدمن | أدمن |
| `podcast_production` | حالة الإنتاج ومراحله | أدمن | أدمن + Actions |
| `audio_meta` | سجل ملفات الصوت المرفوعة | عامة | Actions |
| `myspace_sync` | مزامنة «مساحتي» برمزٍ سرّي بلا حساب | بالرمز | بالرمز |
| `inbox` | رسائل التواصل | أدمن | الخادم |
| `bot_messages` | قوالب رسائل البوت | أدمن | أدمن |

## قواعد ثابتة

- **لا بيانات شخصية في التحليلات:** لا اسم ولا بريد ولا رقم. معرّف جلسةٍ مجهول
  في `sessionStorage` فقط، وعبارات البحث تُنقّى وتُقصّ ويُحجب ما يشبه بريداً أو رقماً.
- **`admin_tool_events` خاصّة بالكامل:** لا تُقرأ إلا بادّعاء `admin`، ولا يُسجَّل
  فيها نصّ مقالٍ ولا فكرة — معرّفات العناصر فقط، ولها حقل `expiresAt` تُبنى عليه
  سياسة الاحتفاظ (١٨٠ يوماً).
- **بصمة الحوار تُحسب من تمثيلٍ canonical ثابت** لا من ترتيب حقول JSON المتغيّر،
  وإلا فشل القفل لاختلاف الترتيب وحده.
- الاستعلامات الحالية تعتمد حقل تاريخٍ واحد، فالفهارس المفردة التلقائية تكفي ولا
  يلزم composite index.
