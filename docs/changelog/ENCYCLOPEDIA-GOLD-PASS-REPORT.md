# Encyclopedia Gold Pass — تقرير التسليم

## النتيجة

أصبحت منظومة «موسوعة تكنولوجيا التعليم» مبنية على ثلاث طبقات مستقلة وقابلة للتدقيق:

1. `originalText`: التفريغ الخام كما أنتجه Buzz.
2. `text` و`displayText`: النص المحافظ المصحح للعرض.
3. `searchText`: نص مطبّع للفهرسة والبحث العربي والمرادفات.

لم تُستبدل أي عبارة غير مؤكدة. القواعد الدلالية الملتبسة تُستبعد، والمقطع غير المفهوم يُحفظ للتدقيق خارج العرض والبحث، والنهاية المبتورة تُحذف من العرض فقط من دون استكمال كلام غير مسموع.

## ما تغيّر وظيفياً

- تصحيح اسمَي الدكتور أحمد حسين الفيلكاوي والدكتور عبدالعزيز العنزي بصيغ معتمدة، مع حفظ الصياغة الخام.
- ربط قاموس الموقع ومرادفات الموسوعة وقواعد التصحيح بمحرك بحث واحد.
- البحث داخل المقاطع الزمنية فقط، وعدم إظهار توقيت عند غياب مقطع موثق.
- ترتيب نتائج الفيديو ومنع تكرار اللحظة نفسها بلا قيمة.
- إبراز عبارة البحث وشرح سبب ظهور النتيجة.
- ربط أقرب صفحة حقيقية من متن الكتاب وفتح PDF عند `#page=`.
- عرض مواد التدريس فقط عند وجود باب وفصل ومحور ونطاق شرائح موثق.
- تصنيف الفيديوهين التعريفيين كمواد تعريفية مستقلة.
- تصنيف الفيديوهات الثلاثة الصامتة `no-speech` ومنع إعادة تفريغها.
- عزل مقاطع «اشترك في القناة» عن البحث مع إبقاء الفيديو في الفهرس.
- تقرير جودة وسجل تصحيحات يوضحان النص الخام، النص المصحح، القاعدة، المصدر، درجة الثقة، الفيديو والتوقيت.
- إضافة موارد Gold Pass صراحةً إلى Cloud Run وCloud Build.

## الحماية من التصحيح الزائد

- أزيلت قاعدة عامة كانت تحوّل الصفة «تكنولوجي» خطأً إلى «تكنولوجيا».
- لا تُطبق القواعد منخفضة الثقة على العرض أو البحث.
- لم تُستكمل عبارة «تطوير قدو-» بكلام غير مسموع؛ حُذفت النهاية المبتورة من العرض فقط.
- المقطع «ما سيصلك تلك المياه» لم يُستبدل بجملة مخترعة؛ حُفظ في `excludedSegments` واستُبعد من العرض والبحث.
- بقيت الأسماء أو العبارات غير المثبتة كما نطقها التفريغ الخام بدلاً من تخمينها.

## قيد بيئة التنفيذ

تعذر تشغيل `vite build` الكامل داخل بيئة التسليم لأن المشروع يشترط Node.js 24 بينما البيئة المتاحة Node.js 22.16، ولأن بوابة حزم npm الداخلية أعادت 404 لحزمة `yargs-parser`. لم يُدّعَ نجاح بناء لم يُنفذ. ملفات TypeScript/TSX المعدلة اجتازت فحص التحويل، وجميع اختبارات الموسوعة والحراس المذكورة نجحت.

بعد وضع الملفات داخل المشروع على جهاز Node.js 24، أمر الإثبات النهائي هو:

```bash
npm ci
npm run build
```
