# تقرير التنفيذ النهائي — القياس والبحث والاستشهادات والبودكاست

## النطاق المنفذ

- توسيع التحليلات الحالية بأحداث الأطلس، العقل الحي، البحث، فتح النتائج، الاستعلامات الصفرية وWeb Vitals.
- إضافة لوحة «الاستخدام الفعلي» داخل لوحة التحليلات الحالية، مع p75 وعدد العينات والفصل بين الهاتف وسطح المكتب.
- إضافة قياس دلالي لأدوات الأدمن الواحد مع مفتاح تعطيل واستبعاد جلسات الاختبار.
- تصحيح القياس الإداري حتى لا يعتبر مجرد الانتقال بين التبويبات «مهمة متروكة».
- إضافة بطاقة صحة المحتوى والتزامن، مع تحقق حي من الصفحة العامة عند الإمكان.
- إضافة BibTeX إلى أداة الاستشهاد الحالية مع النسخ والتنزيل والمفاتيح الثابتة ودعم العربية.
- حفظ حالة بحث الموسوعة والبحث العام في الرابط، وإضافة المشاركة والرجوع والتقدم دون تشغيل صوت تلقائي.
- تنظيم نتائج الموسوعة بتبويبات وعرض تدريجي بدل تحميل النتائج كلها دفعة واحدة.
- توسيع مسار البودكاست اليدوي بحالة مراحل واضحة، منع التكرار، ربط revisionId والبصمة، والاستفادة من checkpoints الموجودة.
- إضافة تدقيق الروابط القديمة وتقارير آلية ومنع الحلقات والسلاسل.
- تحديث README وARCHITECTURE وإضافة PROJECT-STATUS مولد آليًا ووثائق الأنظمة.

## ثوابت لم تتغير

- لم يتغير الحوار اليدوي حرفًا واحدًا.
- لم يستخدم Gemini أو OpenAI لتوليد الحوار أو تعديله.
- لم تُحذف أو تُدمج أي أداة من لوحة التحكم تلقائيًا.
- لم يتغير التصميم جذريًا، وحافظت المكونات الجديدة على RTL والتوكنات البصرية القائمة.

## قيود التحقق في بيئة العمل الحالية

- `npm ci` تعذر بسبب 404 من مرآة الحزم الداخلية لحزمة `yargs-parser`، وليس بسبب package.json.
- بيئة التنفيذ Node 22.16 بينما المشروع يشترط Node 24.
- `npx tsc --noEmit` لا يمكنه التحقق بصورة صحيحة دون حزم React وأنواعها؛ الأخطاء الظاهرة تبدأ من غياب `react` و`react/jsx-runtime`.
- `test-all-user-notes.mjs` يتطلب `Dockerfile` غير موجود في الحزمة الأصلية.
- `vite build` يتطلب تثبيت node_modules، وهو متعذر للسبب أعلاه.

هذه القيود لا تُحوّل الفحوص غير المنفذة إلى فحوص ناجحة؛ يجب تشغيل الأوامر الأربعة في بيئة المشروع المعتادة ذات Node 24 ومرآة npm مكتملة قبل النشر.
