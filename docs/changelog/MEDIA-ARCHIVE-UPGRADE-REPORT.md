# Media Archive Upgrade

## السبب الجذري

صفحة الظهور الإعلامي كانت تعرض اللقاءات كبطاقات فيديو منفصلة، بينما التفريغات القديمة كانت نصوصاً كاملة أو محاور تقريبية لا تمثل دائماً لحظات زمنية موثقة. كما لم يكن هناك مسار موحد يجمع يوتيوب والإذاعة، أو يستورد ملفات Buzz من مجلد العمل المحلي، أو يتيح البحث داخل الكلام والانتقال إلى الثانية الصحيحة.

## النتيجة

- واجهة جديدة باسم «الأرشيف الإعلامي» تجمع المرئي والمسموع.
- بحث موحد داخل المقاطع الزمنية.
- انتقال إلى الثانية الدقيقة داخل مشغل YouTube.
- شاشة تفصيل جديدة تتضمن بطاقة أرشيف، مشغل، نصاً زمنياً، وبحثاً داخل اللقاء.
- دعم المواد الإذاعية من دون إدخال الملفات الصوتية الكبيرة إلى GitHub.
- مستورد VTT ذري من مجلد Buzz المحلي الافتراضي.
- تصحيح محافظ للأسماء الأساسية وبعض التحريفات المؤكدة مع حفظ النص الأصلي.
- توافق رجعي مع التفريغات والمحاور القديمة.

## التشغيل المحلي النهائي

```bash
npm run media:archive:import
npm run media:archive:self-test
```

المسار الافتراضي لملفات VTT:

```text
~/Library/DrAhmad/media-transcription/vtt/
```

يمكن تحديد مسار بديل:

```bash
node scripts/import-media-archive-transcripts.mjs --input=/path/to/vtt
```

## ملاحظة الاستضافة

ملفا الإذاعة لا يدخلان المستودع. بعد اختيار خدمة استضافة صوتية، يوضع الرابط العام في سجل المادة داخل `src/data/media-archive.json`.
