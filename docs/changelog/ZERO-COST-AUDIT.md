# Zero-Cost Audit — مساعد واتساب

الحالة الافتراضية: `ZERO_COST_MODE=true`.

| المكوّن | الحالة | القرار |
|---|---|---|
| Baileys + SQLite | محلي | لا توجد خدمة رسائل أو قاعدة متجهات مدفوعة |
| WhatsApp Cloud API / Meta API | محظور | غير مستخدم |
| OpenAI / Anthropic / Gemini داخل الوكيل | محظور | غير مستخدم |
| Firebase | خارج الوكيل | لا تُرفع أرقام أو جلسات أو نصوص محادثات |
| Azure Speech | معطّل | لا يعمل إلا مع تأكيد F0 وحدود إيقاف محلية |
| التذكيرات | محلية | لا Cron أو Scheduler مدفوع |
| التخزين | محلي | لا توجد ملفات صوت أو جلسة في Git |

الكود الحالي للموقع يحتوي تكاملات Gemini إدارية سابقة خارج هذه المنظومة. الوكيل لا يستدعيها ولا يعتمد عليها. لا يمكن وصف أي خدمة بأنها مجانية إلى الأبد؛ الضمان هنا هو أن الوكيل لا يفتح مزودًا مدفوعًا تلقائيًا وأن بوابة التكلفة توقف Azure قبل الحد المحلي.
