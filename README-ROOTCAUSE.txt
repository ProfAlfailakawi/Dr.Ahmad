## السبب الجذري (باختصار)
1) دفعة «ci: simplify» (3a81319) ألغت خفيةً كل الإصلاحات السابقة:
   مهلات الشبكة، والتقسيم المشدد، وسكربت تنظيف اللوكفايل، وffmpeg من
   workflow النشر — فكان نشر الموقع كله معطلاً منذها (أُصلح وعاد يعمل).
2) package-lock.json كان ملوثاً بروابط مستودع داخلي لبيئة أداة ذكاء
   (applied-caas-gateway…openai.org) → npm يعلق 20 دقيقة على GitHub.
3) التقسيم كان بعدد الكلمات لا بالمدة: 25 كلمة تأملية = 13.1ث > بوابة
   13ث → عزل الحلقة كاملة وإهدار كل Gemini/Azure في كل إعادة.
4) لا استئناف: فشل مقطع واحد = إعادة كل شيء من الصفر.

## أجوبة أسئلتك الثلاثة
1) توليد حلقة من مقال: من غرفة الإنتاج اضغط «🎬 أرسل للتوليد الليلي»
   وستُنتج تلقائياً في الليلة القادمة (2:30 فجراً UTC) عبر نفس بوابات
   الجودة كاملة. أو فوراً: GitHub → Actions → «إطلاق البودكاست الحواري
   المعتمد» → Run workflow مع الـslug. ليست تلقائية عند كتابة المقال
   عمداً — القرار قرارك.
2) الاستماع قبل الاعتماد: صار داخل البطاقة نفسها — مشغّل «🎧 اسمع قبل
   القرار» يظهر لأي حلقة لها صوت (المنشورة، وحتى المرفوضة تسمع نسخة
   المراجعة مع سبب الرفض).
3) الحالة في لقطتك «مسودة» لأن اللوحة المنشورة مبنية قبل هذه الإصلاحات؛
   بعد أول تشغيل ناجح تتحدث تلقائياً بالحالات الحقيقية.
