# خطة تطوير السيرة الذاتية (90 يوماً)

## الهدف
سيرة أكاديمية "أمريكية/دولية" موثّقة بروابط وإثباتات، تُظهر الأثر البحثي والخدمة المهنية، لا مجرد قائمة عضويات.

## الأسبوع 1–2: الأساس
1. اربط Scopus/WoS/OpenAlex/Semantic Scholar بـ ORCID وصحّح الأعمال.
