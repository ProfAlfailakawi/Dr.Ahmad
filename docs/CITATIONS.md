# الاستشهادات

أداةٌ واحدة بخمس صيغ: **APA · MLA · Chicago · RIS · BibTeX**. لا أداة استشهادٍ
موازية — BibTeX أُضيف إلى الأدوات القائمة نفسها.

## المواضع

| المكوّن | أين | الصيغ |
| --- | --- | --- |
| `extras.tsx` → `CiteButton` | الأبحاث والإعلام | APA · MLA · Chicago · BibTeX + تصدير RIS و.bib |
| `CitationCopy.tsx` | المقالات | APA · MLA · BibTeX + تنزيل .bib |
| `QuoteCite.tsx` | مقاطع الكتب | APA · MLA · BibTeX + تنزيل .bib |

المولّد المشترك: `src/lib/bibtex.ts`.

## القواعد

**لا يُكتب ما ليس في البيانات.** الحقل الغائب يُحذف ولا يُملأ بالتخمين، ولا
يُختار نوعٌ لأنه «يستوعب حقولاً أكثر».

### الأنواع

`article` · `book` · `incollection` · `inproceedings` · `phdthesis` ·
`mastersthesis` · `misc`. يستنتجها `inferBibTeXType` من الوعاء الحقيقي (مجلة،
كتاب، مؤتمر، أطروحة)، و`misc` عند غياب الدليل. ولكل نوعٍ حقولُه المسموحة: المجلة
لا تُكتب في كتاب، و`publisher` يصير `school` في الأطروحات.

### أسماء المؤلفين

- الاسم الإنجليزي يُقلب إلى `Family, Given` مع احترام السوابق (`van`, `de`, `ibn`).
- **الاسم العربي لا يُقلب** — بنيته (ابن/عبد/آل/أل التعريف) لا تسمح بقلبٍ آمن،
  فيُلفّ بأقواس حتى لا يفسّره BibTeX على أنه «given family».
- الاسم الذي فيه فاصلةٌ أصلاً يبقى كما هو.
- الفصل بـ`;` أو `|` أو ` and ` أو ` و `، والوصل دائماً بـ` and `.

### المفتاح

ثابتٌ وقابل للتوقّع: `Alfailakawi2024EducationalTechnology`. لا يتغيّر بين
استدعاءين لنفس السجل، بلا فراغٍ ولا رمزٍ خاص، والعربية تُحوَّل بجدولٍ ثابت
(لا عشوائيّ) حتى يبقى المفتاح هو هو. التكرار يُعالَج بلاحقةٍ `a`, `b`, `c`.

### الهروب

مرورٌ واحد يعالج `\ { } % # & _ $ ~ ^`، والأسطر الجديدة تُطوى، و«…» تصير “…”.
الاختصارات الكبيرة (`AI`, `ICT`) تُلفّ بأقواس لتحفظ حالة أحرفها.
**العنوان العربي يبقى Unicode كما هو** — لا تحويل إلى ASCII.

### الملفات

اسمٌ آمن بلا فواصل مسارٍ ولا رموزٍ محجوزة، وBOM في المخرَج حتى تفتح برامج
المراجع الملفَّ العربي بترميزٍ صحيح.

## الاختبارات

```bash
npm run citations:bibtex:self-test    # ١٤ حالة
```

تشمل: بحثاً إنجليزياً كامل البيانات، وبحثاً عربياً، ومؤلفاً واحداً، وعدّة مؤلفين،
وDOI موجوداً وغائباً، ومجلةً بمجلدٍ وعددٍ وصفحات، وكتاباً، وأطروحةً، وعنواناً فيه
أقواسٌ ورموز، واسمَ ملفٍ آمناً، وثباتَ المفتاح، وخلوَّ المخرَج من الحقول الفارغة،
**وبقاءَ RIS وبقية الصيغ دون تغيير**.
