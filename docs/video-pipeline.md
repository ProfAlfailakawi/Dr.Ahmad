# منظومة الفيديو والموشن — خريطة المسارات والفحوص

المدخل: لوحة التحكم ← «الفيديو والموشن» ← «مدخل الفيديو والموشن» (`video-hub`).
المراحل المشتركة: **المصدر ← الخطة ← المعاينة ← الفحص ← التصدير**.

| المسار | الملفات | من يصنع الفيديو؟ |
|---|---|---|
| ريل بمشاهد (المونتير) | `public/monteur/monteur.js`، `export-guard.js`، `MonteurEmbed.tsx`، `monteur-library.ts`، `monteur-drafts.ts` | الموقع يشغّل اللوحة، وتسجّل أنت تبويب الموقع |
| ريل Flow مرسوم | `ReelStudio.tsx`، `reel-motion.ts`، `reel-source.ts` | الموقع يرسم ويسجّل داخل الصفحة (لا علاقة له بخدمة Flow) |
| فيديو منشور متحرك | `design-motion.ts` (والتصميم المتحرك `design-video.ts`) | الموقع |
| خطة تصوير للمخرج الحي | `LiveDirector.tsx`، `live-director.ts` | الموقع يكتب الخطة والبرومبتات فقط؛ المقاطع تُولَّد يدوياً في Flow خارج الموقع ثم تُرفع |

الأطلس (`StoryboardAtlas.tsx` + `storyboard-atlas.ts`) أداة اختيار مادة، لا مسار إنتاج.

## الأساس التقني المشترك: `src/lib/video-capture-core.ts`
- `detectCaptureSupport` / `pickRecorderMime`: دعم المتصفح والصيغة (ترتيب الأفضلية يبقى لكل وحدة).
- `createFrameLoop`: **حلقة رسم واحدة**. كل دورة تسلّح rAF واحداً ومؤقتاً احتياطياً واحداً، وأيّهما سبق يُلغي الآخر. الزمن زمن حائط (الجهاز البطيء يُسقط إطارات ولا يمدّ الفيديو).
- `collectRecording`: يجمع الملف وينقل `onerror` إلى الحلقة فتتوقف فوراً.
- `createCaptureSession`: يغلق المسارات والصوت والعناصر في `finally` مهما كان المسار.
- `verifyRecordedVideo`: يفحص الملف الناتج (الحجم، عدد الإطارات، المدة، المقاس، عيّنات البداية/الوسط/النهاية، الحركة، مستوى الصوت المقيس).
- النتيجة `FileVerification`: `verified` | `unverified` | `failed`. **«جاهز للنشر» لا تُكتب إلا إذا `readyToPublish`**؛ ما تعذّر قياسه يُسمّى في الرسالة.

## الفحوص الحاسمة والاستشارية
حاسمة (ترمي وتمنع التنزيل): حجم الملف، عدد الإطارات، المدة، المقاس.
استشارية (يُنزَّل الملف لكن لا يُقال «جاهز للنشر»): عيّنات الإطارات، الحركة، الصوت، ظهور التبويب.

## المونتير (تسجيل تبويب)
`export-guard.js` (يُحمَّل قبل `monteur.js`): يتحقق من أن المشاركة «تبويب المتصفح» لا نافذة/شاشة، ومن نجاح القص أو ملء الشاشة، ومن اكتمال المشاهد المعروضة، وإيقاف المشاركة المبكر، وصمت الصوت، ثم عيّنات الملف.

## حماية المشاريع (المونتير)
`monteur-drafts.ts`: مخزن تعديلات غير محفوظة لكل مشروع، `status: draft|approved` (غياب الحقل = معتمد)، حقل `aiDraft` لمسودة الذكاء فوق نسخة معتمدة، ومراجعة بفرق قبل اعتماد أي نسخة سابقة.

## الاختبارات
`npm run video:capture:self-test` يشغّل اختبارات: الأساس المشترك، ربط الخطة ببصمة المصدر، مسودات المونتير، حارس التصدير، مدخل الفيديو، والأطلس.
اختبارات الجدولة تحاكي الساعة والمؤقتات (host مُحقَن) — هي اختبار منطق لا تسجيل حقيقي؛ التسجيل الفعلي يُفحص يدوياً في Chrome.
