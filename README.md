# الموقع الرسمي — د. أحمد حسين الفيلكاوي

React 18 · Vite · TypeScript · Tailwind · Framer Motion · React Router · Firestore (اختياري)

```bash
npm install
npm run dev       # تطوير
npm run build     # بناء + توليد ٩٣ صفحة ثابتة + sitemap + RSS
npm run import    # سحب نصوص المقالات من موقعك
```

---

## ⚡ الجديد في هذه النسخة

### ١. توليد ثابت (Prerendering) — الأهم
`npm run build` يولّد **١١١ صفحة HTML ثابتة**، لكل منها وسومها الصحيحة.

**لماذا يهم؟** روبوتات واتساب وتويتر وغوغل **لا تشغّل JavaScript**. قبل هذا، كان رابط مقالك يظهر عارياً عند المشاركة. الآن يظهر بعنوانه ووصفه وصورته.

يُنتج أيضاً: `sitemap.xml` (١١١ رابطاً) · `feed.xml` (RSS) · `404.html` · Schema.org لكل مقال.

### ٢. سماء المقالات — `/atlas`
خريطة بصرية: كل نجمة مقال. **الحجم** = طوله · **الصف** = موضوعه · **الموضع** = زمنه (الأقدم يميناً).
تكشف ما لا تراه القائمة: كثافتك تضاعفت (٣٤ مقالاً في ٢٠٢٥ مقابل ٩ في ٢٠١٩)، والتعليم يبتلع نصف كتاباتك.

### ٣. مولّد بطاقات الاقتباس
يحدّد القارئ جملة داخل المقال ← يظهر زر ← تتولّد **صورة ١٠٨٠×١٠٨٠** فيها الاقتباس واسمك ونطاقك.
تعمل بـ`<canvas>` بلا خادم، وتحترم الوضع الليلي.

### ٤. الوضع الليلي
لوحة كاملة بحبر دافئ (`#EAEAE7` على `#111215`) ولون مميّز أفتح. زر ☾/☀ في الترويسة.
لا وميض عند التحميل (سكربت في `<head>`). يحترم تفضيل نظامك، ويحفظ اختيارك.

### ٥. الاستماع للمقال — بصوت طبيعي

صوت المتصفّح الآلي رديء للعربية، فلا نستخدمه. بدلاً منه: **ملفات MP3 مولّدة مسبقاً** بمحرّك عصبي.

```bash
# ١) أنشئ مورد Speech مجاني على portal.azure.com
# ٢) انسخ المفتاح والمنطقة إلى .env
# ٣) ثم:
npm run audio
```
يمرّ على مقالاتك الـ٦٦ ويصنع `public/audio/<slug>.mp3`.

**الصوت الكويتي**: `ar-KW-FahedNeural` (رجل) أو `ar-KW-NouraNeural` (امرأة).
**التكلفة**: Azure يمنح ٥٠٠ ألف حرف مجاناً شهرياً — ومقالاتك كلها ١٥٠ ألف حرف. أي **صفر**.

يدعم السكربت **ElevenLabs** أيضاً (`TTS_PROVIDER=elevenlabs`) — أطبع صوتاً، لكن بالفصحى.

**المشغّل**: تشغيل/إيقاف · شريط تقدّم قابل للسحب (يبدأ من اليمين) · قفز ١٥ث · سرعة ١× ١.٢٥× ١.٥× · تحميل MP3.

قبل التوليد لا يظهر أي زرّ استماع. لإظهار الصوت الآلي رغم رداءته: `ALLOW_BROWSER_TTS = true` في `data.ts`.

### ٦. نموذج تواصل حقيقي
بأربعة مواضيع (استشارة · محاضرة أو ورشة · لقاء إعلامي · أخرى) ← يكتب في Firestore.
إن لم تُفعَّل Firebase، يعمل الموقع كاملاً ويوجّه الزائر لروابط التواصل.

### ٧. تطبيق مثبَّت (PWA) + قراءة دون إنترنت
`manifest.webmanifest` + `sw.js`. يمكن تثبيت الموقع على الجوّال، والمقالات المقروءة تبقى متاحة بلا إنترنت.

### ٨. RSS
`/feed.xml` — لقرّائك الجادّين. رابط في التذييل.

### ٩. تحليلات محترمة (اختيارية)
اضبط `VITE_PLAUSIBLE_DOMAIN` في `.env` — بلا كوكيز، بلا لافتة موافقة.

## 🔒 إصلاحان أمنيّان مهمّان

**١) قواعد Firestore كانت مفتوحة.** النسخة السابقة سمحت لأي شخص بقراءة رسائلك وتعديلها وحذفها:
```
allow read, update, delete: if true;   // ✘ خطير
```
الآن: الإرسال متاح للجميع، والقراءة **للمشرف المصادَق عليه فقط**، مع تحقّق كامل من صحة الحقول.

**٢) مفاتيح Firebase كانت في ملف مرفوع للمستودع.** الآن تُقرأ من `.env` (المُستثنى في `.gitignore`).
انسخ `.env.example` إلى `.env` وأدخل قيمك.

## 🩹 إصلاح: عناوين مخفيّة
`Reveal` و`FadeUp` كانا يعتمدان `whileInView` وحده. إن لم يُطلق المراقب (خلف شاشة التحميل، أو أثناء انتقال صفحة) يبقى العنوان منزلقاً تحت القناع — **نصّ غير مرئي**.
الآن: `useInView` + شبكة أمان تفحص موضع العنصر بعد ٩٠٠ms وتكشفه إن كان داخل الشاشة.
