حزمة فروق فقط — لا تحتوي المشروع كاملاً ولا ملفات dist أو node_modules أو أسراراً.

السبب الجذري المختصر:
1) زر بدء المقال كان يمر عبر حالة حجز دليل ثانية، فتتبدل الواجهة أو تعود للأعلى بدل دخول مسار الكتابة الواحد. صار النقص ملاحظة مرافقة للمسودة، وزر البدء مساراً واحداً مشغولاً/مكتملًا بوضوح.
2) نشر Cloud Run كان يستدعي gcloud قبل توثيق رسمي ثابت، فصار يستخدم google-github-actions/auth قبل setup-gcloud. كما رُفعت Actions القديمة إلى إصدارات Node الحديثة.
3) بيانات الكتب واللقاءات لم تكن حقولاً كاملة من CMS إلى الصفحة وSchema والبناء الثابت؛ أُكملت السلسلة كلها مع منع اختلاق البيانات غير الموثقة.
4) صفحات اللقاءات لم تكن صفحات مستقلة مفهرسة، ومراقبة CWV والنطاقات وشهادات TLS والتحقق الآلي للروابط كانت تحتاج إغلاقاً موحداً.
5) ملفات HTML الجذرية المكررة وجسر التشغيل العام للمسارات المؤرشفة أبقيا ظلالاً غير لازمة؛ أُزيلا مع إبقاء تحويلات 301 الدقيقة فقط لحماية الفهرسة.

طريقة التطبيق:
- انسخ محتويات الحزمة إلى جذر المشروع مع الحفاظ على المسارات.
- احذف الملفات الواردة في DELETE-FILES.txt.
- شغّل npm install ثم npm run lint ثم npm run build.
- لم يُنفذ أي رفع أو نشر.
